# Design

Mockups for every scene, rendered at 1440x900 (two frames per project scene:
entry state, then scrolled). `flow.png` is the scene order and transitions.
`plan.png` is the build plan.

`generators/` holds the Python scripts that produced the ASCII figures for the
mockups. They are reference only; the site regenerates every figure in
TypeScript from `content/` and `lib/ascii/`.

Numbers in the mockups marked TODO in `content/projects.ts` are placeholders.
